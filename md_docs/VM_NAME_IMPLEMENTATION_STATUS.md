# Implementation Complete: VM Name in ScanLocations

## Summary

Successfully enhanced the `ScanLocation` API to include VM names alongside PVC information. This provides richer metadata for scan operations and makes it easier to identify VM ownership of PVCs.

## What Changed

### 1. API Enhancement
- **New Type**: `VMPVCInfo` struct with `VMName`, `PVCName`, and `PVCPath` fields
- **Updated**: `ScanLocation.VMPVCs` (was `PVCPaths` - simple string array)
- **Source**: The VM name comes from `owner.name` field in `backup.json` dataSnapshots

### 2. Files Modified

#### Go Files
- `api/v1/scaninstance_types.go`
  - Added `VMPVCInfo` struct
  - Changed `ScanLocation.PVCPaths []string` → `ScanLocation.VMPVCs []VMPVCInfo`

#### Python Files
- `datastore-attacher/shared/backup_detection/tvk_detector.py`
  - Updated `_extract_vm_pvc_locations()` to return dict with `vm_name`, `pvc_name`, `pvc_path`
  - Updated `_extract_namespace_backup_metadata()` to use `vm_pvcs` instead of `pvc_paths`
  - Updated `_extract_cluster_backup_metadata()` to use `vm_pvcs` instead of `pvc_paths`

- `datastore-attacher/prescan/cli.py`
  - Updated PVC count calculation to use `loc['vm_pvcs']`
  - Enhanced camelCase conversion to handle nested `vmPVCs` structure
  - Now converts `vm_name` → `vmName`, `pvc_name` → `pvcName`, `pvc_path` → `pvcPath`

#### Generated Files
- `config/crd/bases/threatscanning.trilio.io_scaninstances.yaml`
  - Auto-generated by `make manifests`
  - Contains updated CRD schema with `VMPVCInfo` and `vmPVCs` fields

- `SCANLOCATION_COMPARISON.md` - Before/after comparison with real-world examples

## Data Structure

### Python (Internal - snake_case)
```python
{
    'scan_locations': [
        {
            'namespace': 'dp',
            'backup_uid': '1bbba2bd-...',
            'backup_path': '35a9f73b-.../1bbba2bd-...',
            'vm_pvcs': [
                {
                    'vm_name': 'vm-test',
                    'pvc_name': 'vol-src-as-dv',
                    'pvc_path': '35a9f73b-.../vol-src-as-dv'
                }
            ]
        }
    ]
}
```

### Kubernetes API (External - camelCase)
```json
{
    "scanLocations": [
        {
            "namespace": "dp",
            "backupUID": "1bbba2bd-...",
            "backupPath": "35a9f73b-.../1bbba2bd-...",
            "vmPVCs": [
                {
                    "vmName": "vm-test",
                    "pvcName": "vol-src-as-dv",
                    "pvcPath": "35a9f73b-.../vol-src-as-dv"
                }
            ]
        }
    ]
}
```

## Testing Steps

1. **Update CRD in cluster:**
   ```bash
   kubectl apply -f config/crd/bases/threatscanning.trilio.io_scaninstances.yaml
   ```

2. **Rebuild datastore-attacher image:**
   ```bash
   cd datastore-attacher
   docker build -t <registry>/datastore-attacher:latest .
   docker push <registry>/datastore-attacher:latest
   ```

3. **Redeploy or trigger prescan job**

4. **Verify ScanInstance status:**
   ```bash
   kubectl get scaninstance <name> -o yaml
   ```
   
   Look for:
   ```yaml
   status:
     scanLocations:
     - vmPVCs:
       - vmName: "vm-test"
         pvcName: "vol-src-as-dv"
         pvcPath: "..."
   ```

5. **Check prescan logs:**
   ```bash
   kubectl logs <prescan-job-pod>
   ```
   
   Should see:
   ```
   Found VM PVC: pvc=vol-src-as-dv, vm=vm-test
   ```

## Benefits

✅ **Clear VM Ownership** - Instantly see which VM owns each PVC
✅ **No Path Parsing** - PVC name and VM name explicitly provided
✅ **Better Logging** - Can log meaningful VM names in debug output
✅ **Future-Proof** - Easier to add boot disk filtering logic
✅ **User-Friendly** - Operators can understand which VMs are being scanned

## Breaking Change Notice

⚠️ **This is a breaking API change**

The `pvcPaths` field has been replaced with `vmPVCs`. Any code reading `ScanInstance.status.scanLocations` must be updated:

**Old Code (will break):**
```go
for _, path := range scanLoc.PVCPaths {
    // ...
}
```

**New Code:**
```go
for _, vmPVC := range scanLoc.VMPVCs {
    vmName := vmPVC.VMName
    pvcName := vmPVC.PVCName
    pvcPath := vmPVC.PVCPath
    // ...
}
```
